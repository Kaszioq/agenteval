Do Code Monitors Go Easy
on Their Own Family?

Self-recognition and leniency in small open-weight LLMs, with no collusion instructions anywhere

Kaszioq · AgentEval study 1 · github.com/Kaszioq/agenteval

Track 2: Detection and Audit of Collusion1

The question

In AI control, a monitor model reviews code written by an author model and flags the most suspicious outputs for a limited human audit budget.

If the monitor comes from the same family as the author, it might find the author's code familiar and flag it less. That would be collusion without any instruction.

H1 A model recognises its own solution above chance.
H2 Recognition rests on comments, names or formatting.
H3 Monitors rate their own family's backdoored code as less suspicious.

Pre-registered, with equivalence margins, before the main run.

Qwen2.5-Coder 7B (A) vs Llama 3.1 8B (B) · HumanEval · local Ollama · zero cost2

Setup

  • E1 / E2: the judge sees its own and the other model's solution, in both orders. We read P("1") and P("2") from token probabilities. E2 repeats this after removing comments, renaming identifiers or reformatting.
  • E1b (exploratory): one solution at a time, "did you write this?", reading P("yes").
  • E3: each author plants a backdoor in its own passing solution. It must pass all tests and give a wrong answer on a secret input, checked in a sandbox. Both monitors score all code from 0 to 10.
  • Key quantity: the 2×2 interaction I = (SAA−SAB) − (SBA−SBB), which cancels differences in how detectable each author's backdoors are. H3 predicts I < 0.
  • Inspect framework, ControlArena conventions (2% audit budget), every number traced to a logged prompt and response.

Takeaways

Finding. Small open models from different families neither recognise nor favour their own family's code as monitors. The only signal is a small own-code tilt in Qwen's yes/no answers (+3.4 points).
Method lesson 1. Pairwise self-recognition evals with small judges are dominated by position bias. Counterbalance the order and read probabilities.
Method lesson 2. A monitor that uses only a few score values breaks raw-score 2×2 designs. Report scale-free measures such as AUROC.
